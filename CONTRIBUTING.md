# Contributing

This is a solo practitioner's repo. Pull requests are welcome to read and learn from, but they are not reviewed or merged. Fork it and make it yours rather than waiting on a review here.

## If you find a bug or have a question

Open an issue. Issues are enabled on this repo. It may not get a response quickly, or at all, but it is read. If the bug is a security problem, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.

## Changes to this repo

The maintainer's own changes go in a pull request with a fragment in [`changelog.d/`](changelog.d/README.md), compiled into [`CHANGELOG.md`](CHANGELOG.md) at tag time. A pull request that moves a [`docs/ROADMAP.md`](docs/ROADMAP.md) item adds a status fragment in `changelog.d/roadmap/` rather than editing that file. Neither shared file is edited by hand; CI fails a pull request that does.

## Code of conduct

Be direct, be honest, don't waste anyone's time including your own. There is no formal code of conduct beyond that for a single-maintainer repo of this size. If that changes (more contributors, more traffic), it gets revisited.
