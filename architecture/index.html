Spine — linear, three passes.

1
Prompt
capture raw
›

Echo the request back in your own words. Don't clean it, don't solve it, don't classify it yet. Name the one or two real unknowns instead of guessing them away.

Hands off: the request, plainly, plus the real unknowns.
2
Orchestrator
first pass · read the field
›

Decompose into workstreams. Estimate blast radius. Draft a candidate routing table from the existing skills. Frames the work. Deploys nothing yet.

Hands off: workstreams, blast radius, candidate routing.
3
Strategic Coordinator
the digital twin · second pass
›

The neck of the balloon. Grounds on stack-data, applies the COO guardrails, then commits: these agents deploy, in this shape, for these reasons. Flags every contested decision. The only layer allowed to say none of this is worth doing now.

Hands off: a committed deployment plan, contested calls flagged.

Balloon — jump out, then come back.

Divergence
4
Jump out
parallel specialist agents
›

Deploy the committed agents in parallel, each isolated on a tight brief. Isolation is what keeps their outputs genuinely different.

✦
Mini-arenas
optional · recommended by default
›

For each contested decision, seat two or three agents on opposing sides. One exchange minimum. Conflict as a generative force. The output is a spread of distinct options with each cost named, not a blend.

The Arena, from seed-bed (Claim → Arena), scaled to one decision.
Convergence
5
Come back together
twin reels it in
›

Merge the outputs, resolve each arena's spread into one ranked proposal: recommended first, alternatives kept visible, the cost of each named. Unresolved tensions get surfaced, not buried.

Gate.

6
Quality Assurance
at least one · adversarial
›

Nothing ships before the gate. Check voice, grounding, constraints, and fit against the Pass 1 prompt.

On fail: loop back to divergence with the failure named.
