# Interpreters and packages, one place. `pip install -r requirements.txt` installs
# the packages for the Python 3.14 column into a venv outside the repository; CI does
# exactly that (.github/workflows/ci.yml). On the Mac:
#   /opt/homebrew/bin/python3.14 -m venv ~/.venvs/rp-tools
#   ~/.venvs/rp-tools/bin/python -m pip install -r requirements.txt
# Pillow 11.3.0 was the last release for 3.9, and its security fixes (12.2 and later) need 3.10+,
# so lutlab, rpstills and vertcut moved off Xcode's 3.9 (ROADMAP, Amendment 3, item 30).
#
# Interpreter per tool
#   scripts/*.sh, tools/vertcut/vertcut             bash 3.2+ and coreutils.
#   production/resolve_mcp.py (Resolve MCP server)  /usr/bin/python3 (Xcode's 3.9). Stdlib only. Stays on 3.9.
#   production/rpresolve/, resolve_workflow.py      3.9 under the MCP server. numpy for measure, sync, color, trim review:
#                                                   the 3.9 line below (numpy 2.0.2, the last NumPy for 3.9), which CI's
#                                                   rpresolve-tests-3-9 job installs alone; the 3.14 pins also run them.
#   production/lutlab/                              ~/.venvs/rp-tools (Homebrew 3.14). numpy, scipy, Pillow, OpenCV.
#   production/rpstills/                            ~/.venvs/rp-tools (3.14). numpy, Pillow, OpenCV, imagehash.
#   tools/vertcut/lib/vertcut_cut.py                ~/.venvs/rp-tools (3.14). Pillow.
#   production/resolve_survey.py                    /opt/homebrew/bin/python3.14. Stdlib only, but it
#                                                   reads Resolve's zstd blobs with compression.zstd,
#                                                   which exists only from 3.14. On 3.9 its 24 zstd tests skip.
#
# Programs outside pip
#   ffmpeg, ffprobe   production/, tools/vertcut. Homebrew on the Mac; preinstalled on CI's ubuntu-latest.
#   exiftool          optional, read by detect when present.
#   mlx-whisper       vertcut transcribe only, Apple silicon, so not pinned in this file (CI runs on Linux).
#                     Into the same venv, held at these pins:
#                     ~/.venvs/rp-tools/bin/python -m pip install -c requirements.txt mlx-whisper==0.4.3
#   DaVinci Resolve   its own scripting module, loaded by the MCP server at run time. Not on pip.
#
# Environment overrides
# Every variable the tools read. The defaults suit a Homebrew Mac; set the variable when a program
# lives elsewhere (Intel Mac, MacPorts, Linux, CI). Unset means the default.
#
#   Variable                     Read by                           Default                                   Set it when
#   RPRESOLVE_FFMPEG             rpresolve measure, sync,          /opt/homebrew/bin/ffmpeg                  ffmpeg is not at the default path.
#                                delivercheck, reframe, cutlist,
#                                vertcut segkind
#   RPRESOLVE_FFPROBE            rpresolve measure, sync,          /opt/homebrew/bin/ffprobe                 ffprobe is not at the default path.
#                                delivercheck, detect
#   RPRESOLVE_EXIFTOOL           rpresolve detect                  /usr/local/bin/exiftool                   exiftool is not at the default path.
#   RPRESOLVE_SURVEY_PYTHON      rpresolve workflows (survey)      /opt/homebrew/bin/python3.14              a Python 3.14+ lives elsewhere.
#   RPRESOLVE_CONFIG             Resolve MCP deliver_check         none (resolve-config.json alone)          you keep a local overlay of the config.
#   RPRESOLVE_LOCK               rpresolve ResolveLock             ~/Library/Caches/rpresolve/resolve.lock   the lock file needs another place.
#   RPRESOLVE_MCP_OUT            Resolve MCP server                ~/Library/Caches/rpresolve/mcp            tool output needs another folder.
#   RPRESOLVE_MCP_JOURNAL        Resolve MCP server                ~/Library/Logs/rpresolve-mcp/writes.jsonl the write journal needs another file.
#   RPRESOLVE_MCP_NO_RESOLVE     Resolve MCP session               unset                                     tests: 1 makes every Resolve connect fail.
#   RPRESOLVE_SETTINGS_GUARD     rpresolve settingsguard           off                                       you want new-timeline settings reported: on, 1, yes or true.
#   VERTCUT_PYTHON               tools/vertcut/vertcut             ~/.venvs/rp-tools/bin/python              the Python with Pillow is another one.
#   VERTCUT_MLX_WHISPER          tools/vertcut/vertcut transcribe  ~/.venvs/rp-tools/bin/mlx_whisper         mlx_whisper is installed elsewhere.
#   RPSTILLS_LIGHTCRAFT          rpstills develop (trial backend)  unset (apple backend only)                you trial the LightCraft RAW backend: the lightcraft-cli path.
#   FFMPEG, FFPROBE, PYTHON, CP  tools/ipad-probe (CP: only       ffmpeg, ffprobe, python3, cp from PATH    a-Shell or another shell names them differently.
#                                verify-copy)
#   LUTLAB_OUT                   production/lutlab                 none                                      always, unless every command gets --out.
#   LUTLAB_BRAW2PPM              lutlab/verify.py (BRAW)            lutlab/braw/braw2ppm, beside the source   the BRAW helper was built elsewhere.
#   BRAW_SDK                     lutlab/braw/build.sh, braw2ppm    /Applications/Blackmagic RAW/Blackmagic   the Blackmagic RAW SDK is installed elsewhere.
#                                                                  RAW SDK/Mac
#   LUTLAB_SKIP_RENDER_VERIFY    production/tests/test_lutlab.py   unset                                     tests: any value skips the render-verify test. Needed with
#                                                                                                            an ffmpeg build whose colour differs from Homebrew's (CI's apt build).
#   RPRESOLVE_WHISPER_MODEL      rpresolve transcribe (mlx)        mlx-community/whisper-large-v3-turbo      another mlx-whisper model or a local folder.
#   RPRESOLVE_WHISPER_CPP_MODEL  rpresolve transcribe              none (--model required)                   the whisper.cpp model file lives in one place.
#                                (whisper.cpp)
#   RPRESOLVE_WHISPER_CPP_TIMEOUT_S
#                                rpresolve transcribe              4x the audio length, at least 600 s;      whisper-cli needs longer or shorter: seconds, positive.
#                                (whisper.cpp)                     6 h when the length is unreadable
#   RPRESOLVE_RNNOISE_MODEL      rpresolve mixbuild (arnndn)       none (the step's model: required)         one .rnnn model serves every arnndn step.
#   CHROME                       tools/ograf-render                Google Chrome, then chromium on PATH      Chrome is elsewhere (or --chrome PATH).
#   OGRAF_LINT                   tools/ograf-render --lint         Resolve's lint-ograf.py                   Resolve's OGraf linter is elsewhere.
#   RCLONE_BIN                   production/offload.sh safe        rclone from PATH                          rclone has another name or path.
#   CI                           tools/ograf-render                unset                                     set by CI runners: Chrome starts with --no-sandbox.
#   BURST_GATE_DENYLIST          scripts/burst-gate                unset (no extra patterns)                 you keep private regexes for the G2 privacy scan.
#   DD_BIN, DF_BIN               production/offload.sh             dd, df from PATH                          tests: stand-ins for the system tools.
#   DISKUTIL_BIN                 production/offload.sh             diskutil from PATH                        tests: a stand-in for diskutil.
#   OFFLOAD_NOW                  production/offload.sh             unset (the clock)                         tests: a fixed UTC time stamp.
#   RESOLVE_WORKFLOW             tools/ograf-render/test.mjs       production/resolve_workflow.py            tests: another copy of the workflow script.
#
# The tools do not find ffmpeg the same way. rpresolve reads RPRESOLVE_FFMPEG and RPRESOLVE_FFPROBE and
# otherwise uses the Homebrew paths. lutlab and tools/vertcut call bare ffmpeg and ffprobe from PATH, so
# for lutlab the fix is PATH, and RPRESOLVE_FFMPEG does not reach it.
#
# markdown serves scripts/build-site.py (the GitHub Pages site build) and nothing else. The deploy workflow and
# the pull-request site build both install the version pinned below.
#
# Pins are the versions CI installs and the suite was run against on 3.14 (numpy 2.3.5 and scipy 1.16.3
# have 3.14 wheels; Pillow 12.3 is the release the security alerts need). The marked numpy line is for
# rpresolve on 3.9 only. The Mac's own 3.9 set (numpy 2.0.2, scipy 1.13.1, opencv 5.0.0.93) gave
# identical lutlab Delta E figures.
numpy==2.3.5; python_version >= "3.10"
numpy==2.0.2; python_version < "3.10"
scipy==1.16.3
Pillow==12.3.0
opencv-python-headless==4.10.0.84
imagehash==4.3.2
markdown==3.9
