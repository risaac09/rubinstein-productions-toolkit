offload.sh lite now compares device numbers (stat) between the card and the lite folder, so it refuses any folder on the card (not only the card root) and refuses when it cannot tell. It also lists the card at its recorded path and refuses unless that is the same card, so a stale mount folder or a same-named card never passes. `copy` records the card's mount path in a `<card>.card-root` sidecar, also when it finds the card already offloaded (run `copy` again on a copy made before this change), and `card mv` moves that sidecar. Run `lite` with the card still in its reader, before `safe --lite`.
