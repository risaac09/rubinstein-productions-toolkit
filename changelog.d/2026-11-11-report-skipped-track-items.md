apply_effect and vertical_apply now return a skipped list naming every track item they leave out (a dissolve, title, generator or compound clip: raw position, name, reason), and the dry run's summary counts them. Clip numbering is unchanged: a skipped item never shifts the others. The skipped rows are taken from the same item list and positions the targets use, so the two cannot disagree. The refusals for a clip count that does not match (a clip number past the end in apply_effect, a crops.json count mismatch in vertical_apply) now name the skipped items. The reason is one fixed text because the item API gives no kind. An offline clip is believed to keep its media pool item, so it is counted and not reported (believed, not live-tested).
