Add rpresolve.renderloop: a render-and-check loop on lavfi fixtures. One runner per artifact type (graphic, sound, cut, grade) renders a fixture with ffmpeg, runs overlay-check, the audio-report flags, qc or perceive --ref, prints a FAIL-first table with a version line per round, calls a caller-supplied fix step, and stops at 5 rounds with the table. Known limit, tested: it verifies the render against the spec, so an unmeetable spec hands back at the cap and a wrong but meetable spec passes. Offline; never touches Resolve.
