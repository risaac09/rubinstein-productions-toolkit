New command project: start a project from a camera card, resumable. It copies and verifies a card volume with offload.sh, records the project slug, runs detect, lists what the record cannot answer with contact sheets of those clips, calls a configured indexer and the sheets command, then prints the set_color_management call for the managed-dwg preset and waits on a person creating the Resolve project. State is project.json under the work root, paths come from the file named by RP_PIPELINE_CONFIG (production/project.example.json), every step that writes is a dry run until --apply, and project status names the next command for the hand steps and whether the card may be formatted. sheets gains --only.
