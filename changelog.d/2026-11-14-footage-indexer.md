The footage indexer joins the toolkit as production/footage_index: search a video archive by description (SigLIP embeddings, local captions, SQLite), rank edit methods against a shoot, fill slots through a quality gate, and check plans against an exclude list. Every path, root, restricted folder and review file is a setting, read from the footage_index section of the file named by RP_PIPELINE_CONFIG or from the environment, and with no configuration it runs on one folder given with --root. Tests use synthetic clips and run in a new CI job.
