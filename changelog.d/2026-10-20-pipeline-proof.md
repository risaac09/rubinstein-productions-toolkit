New `resolve_workflow.py pipeline-proof TEST REFERENCE`: an offline PASS or FAIL for a test render against a reference render (or Resolve's own decode exported as a file). Rows for frame count and size, legal or full range, a gamma or level shift with the measured offset, per-frame luma and chroma shift, PSNR (45 dB), SSIM (0.99) and VMAF (95, "not available" when ffmpeg has no libvmaf); all thresholds overridable. The help text names the trap: Resolve decodes log H.264 about 25 code values darker than ffmpeg. `measure.signal_frames` now reads per-frame signalstats and `legal_range` uses it. Gate G1 of the card-to-delivery video pipeline.
