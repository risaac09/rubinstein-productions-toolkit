Add `python3 -m rpresolve.mixbuild`: an offline mix builder. A YAML (or JSON) mix spec becomes one ffmpeg filter graph per stem and one for the mix (gain, fades, high-pass, EQ, de-ess, afftdn and arnndn denoise, a compressor, sidechain ducking, two-pass loudnorm and an oversampled true-peak limiter), rendered to 24-bit WAV on copies. The same spec and inputs give byte-identical files; it refuses to write over a source or inside a git tree; `--report` measures every output with audio-report; denoise candidates render beside the stem for comparison. `mixbuild ab` cuts the same span from two or more files, matches their loudness within 0.5 LU, shuffles them to A, B, C and seals the key in a read-only file. (VP-128)
