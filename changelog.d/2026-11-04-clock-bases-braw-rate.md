shoot-table reads each camera's wall clock: PYXIS and DJI tags are UTC, so a file name that holds the wall clock moves the tag by the whole zone, and a new clock_base column says where each row's clock came from. Runs that passed --offset for the zone must drop it. detect no longer calls a BRAW clip VFR: a long last packet moved ffprobe's rates, so BRAW now reads no, or off-speed from the camera's OffspeedFrameTime, and shoot-table agrees because ffprobe now reads BRAW headers there too.
