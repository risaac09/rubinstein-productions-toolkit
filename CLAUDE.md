# CLAUDE.md

## What this repo is
The public toolkit: methodology, templates, docs, generic CLI tools, and an export of the two deployment kits (`phase-zero/`, `public-kit/`), whose source lives in the private stack-data repo since 2026-10-07. Take what's useful is the license posture. Business strategy, brand/voice prompts, and RP-specific production tooling live in the private `rp-intranet` — an August 2026 audit found this repo's older "nothing private lands here" claim wasn't actually true and moved that content out. A second pass on 2026-08-23 removed what that audit's scope missed: the eval corpus, service-tier pricing, revenue projections, and a snapshot of the local permission allow list. See README.md's "What's Not Here" for the full accounting. Before adding anything here, assume public means public.

## The one guardrail
`phase-zero/` and `public-kit/` here are an export. Never edit them in this repo. Their source is `kit/phase-zero/` and `kit/public-kit/` in the private stack-data repo (stack-data decision "The kit source lives in stack-data; the toolkit carries an export", 2026-10-07). Edit there, then run stack-data `scripts/sd-kit-export` onto a branch of this repo: it privacy-scans what would leave, mirrors both directories byte for byte, and redeploys this repo's own `.claude/`. Title the commit and its PR with the line it prints, `Export kit from stack-data <sha>`; any other commit touching these two directories is the decision's falsifier. The two kits share one installer, `phase-zero/install.sh`, and everything below describes how they deploy, run from the source in stack-data.

**phase-zero** (AI-agent session infrastructure): edit the source in stack-data, then redeploy with `phase-zero/install.sh --all <parent-dir>`. The deployed `.claude/` copies in the consuming repos are byte-identical output; never edit one in place, the next install overwrites it and the edit dies silently. Consuming repos: the `CONSUMERS` allowlist in `phase-zero/install.sh` is the list of record (history of additions and removals: git log and stack-data `docs/DECISIONS.md`). A direct one-repository install remains available for an intentional exception.

**public-kit** (public-repo hygiene: license templates, README shape, CONTRIBUTING/SECURITY templates, public voice rules), added 2026-08-21: edit the source in stack-data, then redeploy with `phase-zero/install.sh --public --all <parent-dir>`. Deploys into `.claude/public-kit/`, never repo root — the LICENSE/README/CONTRIBUTING/SECURITY templates are references a human promotes deliberately, not auto-applied files. Its consumers are the repos that are actually public. The roster is not listed here: run `phase-zero/install.sh --public --list`, which reads it at runtime from the private stack-data registry and exits 2 when the registry or jq is missing. Redeploy as pull requests with `phase-zero/redeploy-prs.sh --public`. Fully independent of `CONSUMERS` — `rp-intranet` takes phase-zero without public-kit (private, no public-hygiene need), `risaac09` takes public-kit without phase-zero (explicitly not a phase-zero consumer), some repos take both, most take neither.
